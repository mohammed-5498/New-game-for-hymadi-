# مدينة العصابات (Gang City)

لعبة استراتيجية في الوقت الحقيقي للجوال، بزاوية كاميرا مائلة. عصابات تتقاتل للسيطرة على أحياء مدينة قديمة.

المشروع الآن **Godot 4.x (GDScript)** ويُبنى كتطبيق أندرويد. نسخة المتصفح القديمة باقية في الجذر للرجوع فقط.

- الوصف الكامل للعبة: [`docs/GAME_SPEC.md`](docs/GAME_SPEC.md)
- قواعد العمل على المشروع: [`CLAUDE.md`](CLAUDE.md)
- مشروع Godot وتفاصيله: [`godot/README_GODOT.md`](godot/README_GODOT.md)

## 📱 كيف تنزّل آخر نسخة APK على جوالك

1. افتح من الجوال: **[صفحة Actions](../../actions/workflows/android.yml)** ← اضغط على آخر تشغيل ناجح (علامة ✅ خضراء).
2. انزل لأسفل الصفحة إلى **Artifacts** واضغط **GangCity-apk** لتنزيله، ثم فك الضغط عن الملف وثبّت `GangCity.apk`.

> لازم تكون مسجّل دخول في GitHub حتى يشتغل زر التنزيل.
> عند أول تثبيت سيطلب الجوال السماح بتثبيت تطبيقات من مصدر غير معروف — اسمح له.
> الملف موقّع بمفتاح تجريبي (debug)، وهذا كافٍ للتجربة الشخصية ولا يصلح لنشره على Google Play.

لبناء نسخة جديدة يدوياً: صفحة Actions ← **بناء تطبيق أندرويد** ← **Run workflow**.

## كيف تشغّلها على الكمبيوتر

افتح Godot 4.3 أو أحدث، اضغط **Import**، واختر `godot/project.godot`، ثم **F5**.

## نسخة المتصفح القديمة (للرجوع فقط)

```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000` في المتصفح.
